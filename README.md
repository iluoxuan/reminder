# 提醒助手

一个简单的提醒工具，可以帮助你定时提醒喝水或运动。

## 功能特点

- 支持喝水提醒和运动提醒
- 可自定义提醒时间间隔
- 支持中英文切换
- 系统托盘运行
- 最小化到托盘
- 支持打赏

## 安装说明

1. 确保已安装 Python 3.8 或更高版本
2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```

## 运行方法

```bash
python reminder_app.py
```

## 使用说明

1. 选择提醒类型（喝水/运动）
2. 设置提醒时间间隔（1-240分钟）
3. 点击"开始提醒"按钮启动提醒
4. 可以最小化到系统托盘继续运行
5. 右键点击托盘图标可以显示/退出程序

## 系统要求

- Windows 10/11
- macOS 10.15 或更高版本
- Python 3.8 或更高版本
